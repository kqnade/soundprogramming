# 標本化定理と FIR フィルタの練習問題

## 1. 最高周波数が 24 kHz の信号の標本化

出典：`../slide/Wk1-SignalProcessing_2026.pdf`、21ページ。

標本化定理より、標本化周波数は原信号の最高周波数の2倍を基準に決める。

\[
f_s = 2f_{\max}=2\times24=48\ \mathrm{kHz}
\]

したがって、設問で求める標本化周波数の下限の数値は **48 kHz** である。

ただし、24 kHz の成分が実際に存在する信号を任意の位相について復元したい場合、48 kHz ちょうどでは十分とは限らない。例えば `sin(2π × 24000t)` を48 kHzで標本化すると、すべての標本が `sin(πn) = 0` となり、元の振幅を復元できない。このため、厳密には最高周波数に対して `fs > 48 kHz` とし、さらに実際のアンチエイリアスフィルタの遷移帯域にも余裕を持たせる必要がある。

## 2. 2タップ移動平均フィルタのインパルス応答

出典：`../slide/Wk9-DigitalFilter.pdf`、28ページ。

図のフィルタは、現在の入力と1標本前の入力をそれぞれ0.5倍して足している。初期状態をゼロとすると、差分方程式は

\[
y[n]=\frac12x[n]+\frac12x[n-1]
\]

である。単位インパルス `x[n] = δ[n]` に対する応答は

\[
h[n]=\frac12\delta[n]+\frac12\delta[n-1]
\]

となる。

| 標本番号 n | 0 | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|---:|
| 入力 x[n] | 1 | 0 | 0 | 0 | 0 |
| 遅延入力 x[n−1] | 0 | 1 | 0 | 0 | 0 |
| 出力 y[n] | 0.5 | 0.5 | 0 | 0 | 0 |

インパルス応答が2標本で終わるため、これは有限インパルス応答（FIR）フィルタである。

## 3. ナイキスト周波数の信号を入力した場合

出典：`../slide/Wk9-DigitalFilter.pdf`、29ページ。

入力を、時刻0から始まる `x[n] = (−1)^n` とし、`n < 0` ではゼロとする。

| 標本番号 n | 0 | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|---:|
| 入力 x[n] | 1 | −1 | 1 | −1 | 1 |
| 遅延入力 x[n−1] | 0 | 1 | −1 | 1 | −1 |
| 出力 y[n] | 0.5 | 0 | 0 | 0 | 0 |

最初の標本だけは過去の入力がゼロなので0.5が出力される。その後は隣接する正負の標本が打ち消し合い、出力はゼロになる。過去から同じ交互信号が継続している定常状態を仮定した場合は、最初から出力がゼロになる。

周波数応答からも、この結果を確認できる。角周波数 `ω` の単位を rad/sample とすると、

\[
H(e^{j\omega})=\frac12(1+e^{-j\omega})
=e^{-j\omega/2}\cos\frac{\omega}{2}
\]

であり、

\[
|H(e^{j\omega})|=\left|\cos\frac{\omega}{2}\right|
\]

となる。直流では利得が1、ナイキスト周波数 `ω = π` では利得が0なので、このフィルタは低域を通し高域を減衰させる。

`0 ≤ ω < π` では位相が `−ω/2` で、群遅延は0.5標本である。これは周波数成分の位相から求めた遅延であり、実装で未来の半標本を参照するという意味ではない。ナイキスト点では出力振幅がゼロとなるため、その点の位相は定義できない。

## 4. 考察

2つの標本の平均を取るだけでも、ゆっくり変化する成分は残り、標本ごとに符号が反転する成分は消える。この性質は、インパルス応答との畳み込みと、周波数応答の両方から説明できる。

ただし、すべての雑音が除去できるわけではない。必要な信号と雑音が同じ周波数帯域に存在すれば、一方だけをこのフィルタで取り除くことはできない。また、標本化の段階で折り返した成分は元の帯域内信号と区別できなくなるため、A/D変換前の帯域制限が重要である。
