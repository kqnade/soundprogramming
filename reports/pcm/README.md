# C言語による音声処理

```sh
make -C reports/pcm
reports/pcm/build/synth A4 > /tmp/A.wav
```

コマンドはリポジトリのルートから実行する。共有ライブラリと14個のアプリケーションを `build/` に生成する。

| アプリ | 入力・用途 |
|---|---|
| `sin [音名/Hz [bit]]` | 48 kHz・モノラル・1秒の正弦波 |
| `sin2 [音名/Hz [bit [ch [fs]]]]` | PCM属性を指定する正弦波 |
| `wave [saw/tri/sqr/sin [音名/Hz]]` | 基本波形の直接生成。非正弦波には標本化による折返しがあり得る |
| `synth [音名/Hz]` | 帯域制限した奇数次加算合成とADSR |
| `thru` | 標準入力のWAVを読み書きする |
| `rate [倍率]` | 標準入力のWAVの標本化周波数・音長を変更 |
| `seq file.wav ...` | PCM属性の等しいWAVの連結 |
| `mix file.wav ...` | PCM属性の等しいWAVの平均による混合 |
| `dft [file.wav [N [start]]]` | DFT/IDFT、既定N=480 |
| `fft [file.wav [N [start]]]` | FFT、既定N=8192 |
| `ft [file.wav [N [start]]]` | DFT/FFT比較、既定N=1024 |
| `ip [秒 [bit]]` | 振幅0.9のインパルス、既定2秒・16 bit |
| `iir [a1 a2 a3]` | 標準入力の帰還型フィルタ、出力長は入力と同じ |
| `fir ir.wav` | 標準入力とモノラルIRの線形畳み込み。利得の自動正規化なし |

DFT系以外の処理結果は標準出力のWAVとして出力する。情報は標準エラーへ出力する。DFT系は実行ディレクトリにテキストを保存するため、実験ごとに出力先を分ける。

ライブラリの対象は基本fmt形式の整数PCM、8/16/24/32 bit、1または2チャネル、リトルエンディアン環境。内部配列と出力サイズの制約があるため、大容量の汎用音声変換用途には適さない。

全実験と回帰テストは [レポート集の手順](../README.md#ビルドと検証) を参照。
